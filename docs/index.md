# LMS operator handbook

Procedures for leftover settings on an LMS you administer.
Each page is a check you run on a test site you own.
Open edX and Totara notes are marked alpha where the connector is alpha.

- Chamilo 1.11 still has configuration.dist.php from install day
- Open edX still shows Staff Debug to course staff
- Totara still serves the course index before login
- WordPress still has Anyone can register on the LMS
- Laravel LOG_LEVEL is still debug on the LMS
